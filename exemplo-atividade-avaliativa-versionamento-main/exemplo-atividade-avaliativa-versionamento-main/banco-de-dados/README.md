CREATE TABLE public.irrigacao (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    sensor1 INTEGER,
    sensor2 INTEGER,
    sensor3 INTEGER,
    media INTEGER,
    luminosidade INTEGER,
    temperatura REAL,
    bomba TEXT
);
2. Descrição técnica
Criação da tabela Irrigação – Supabase
A tabela irrigacao foi criada no banco de dados PostgreSQL do Supabase com o objetivo de armazenar os dados coletados pelo sistema de monitoramento de plantas IrrigaTech.

A tabela recebe e organiza as informações dos sensores conectados ao sistema, permitindo que os dados sejam armazenados e posteriormente consultados pelo aplicativo.

Estrutura da tabela
Coluna	Tipo	Função
id	BIGINT	Identificador único do registro
created_at	TIMESTAMPTZ	Data e horário do registro
sensor1	INTEGER	Leitura do sensor de umidade 1
sensor2	INTEGER	Leitura do sensor de umidade 2
sensor3	INTEGER	Leitura do sensor de umidade 3
media	INTEGER	Média das leituras
luminosidade	INTEGER	Valor de luminosidade
temperatura	REAL	Temperatura registrada
bomba	TEXT	Informação sobre o estado da bomba
Como foi desenvolvido
A tabela foi estruturada utilizando o PostgreSQL, disponibilizado pela plataforma Supabase.

Foi definido um identificador automático (id) para cada registro, além de uma coluna created_at, responsável por registrar automaticamente a data e o horário de inserção.

As demais colunas foram definidas de acordo com os dados enviados pelo sistema de monitoramento, utilizando tipos numéricos para as leituras dos sensores e texto para a informação da bomba.

Integração com o IrrigaTech
O aplicativo IrrigaTech utiliza o Supabase para consultar os dados armazenados na tabela irrigacao.

A integração permite:

Consultar as últimas leituras dos sensores.

Exibir os níveis de umidade do solo.

Consultar a luminosidade.

Receber novas informações por meio do Supabase Realtime.
